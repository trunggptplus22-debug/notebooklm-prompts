# Start Here — Choose a Prompt by Describing the Problem

You do not need to know the prompt name, category, method, or technical terminology.

## What to do

Describe the situation in ordinary language. Include only what is already known. For example:

- "I have an idea but do not know whether it is feasible."
- "I have a technical problem and cannot identify the cause."
- "I need to build an AI system but do not know which architecture to use."
- "I have several books and need to turn their contents into an operational knowledge base."
- "I need to compare two methods and determine which is more reliable."
- "I have a model or algorithm and want to find its weaknesses."

Paste this message into the AI:

> I need help choosing the right task and method. I will describe my situation in ordinary language. Do not ask me to choose a prompt or category. First identify what outcome I need, what is known, what is missing, and what kind of work is required. Then select the single most suitable prompt from the Prompt Library. Explain briefly why it is the best match and what it will produce. If essential information is missing, ask only the one question that most affects the choice. If enough information is available, proceed without asking me to select anything.

## If you already know the task

Go directly to [Prompt Router](PROMPT_ROUTER.md). It maps practical goals to the best matching prompt.

## Important

- Start with the problem, not the prompt catalogue.
- The AI should choose the prompt. Do not make the user compare similar filenames.
- Recommend one best-fit prompt by default. Show alternatives only when they produce materially different outcomes.
- If no existing prompt fits, say so and propose the smallest necessary new prompt. Do not force a poor match.
