# Conceptual Explainer with Technical Integrity

Explain [INSERT COMPLEX CONCEPT] to an intelligent audience unfamiliar with the domain.

Start with a precise definition, then explain the mechanism using one concrete example. Introduce analogy only where it preserves the structure; explicitly state where the analogy stops working. Show the key relationships visually. Avoid replacing technical distinctions with vague simplifications. Separate established knowledge, school-specific doctrine, interpretation, and hypothesis. End with what the concept can explain, what it cannot explain, and one question that deepens understanding.
