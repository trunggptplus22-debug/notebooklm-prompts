# Technical Onboarding Video

Design an onboarding video that enables a new contributor to understand and safely work on [INSERT SYSTEM / RESEARCH PROJECT].

Explain system purpose, terminology, repository or module structure, data contracts, execution sequence, rule provenance, coding conventions, test commands if supplied, common failure modes, and contribution workflow. Show one end-to-end example. Identify what a contributor must not change without checking dependencies. Do not invent commands or repository paths. End with a practical first task and a checklist for verifying the change.
