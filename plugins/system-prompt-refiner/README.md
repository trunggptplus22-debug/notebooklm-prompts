# System Prompt Refiner Plugin

Portable Agent Plugin bundle for clients that support Agent Plugins 1.0 and Agent Skills.

## Included skill

- `skills/system-prompt-refiner/SKILL.md` — controlled prompt diagnosis, Conservative Refine and Deep Enhance modes, semantic diff, invariant checks, test design, comparative evaluation, and release decisions.
- `skills/system-prompt-refiner/INVARIANTS.md` — blocking invariant policy.
- `skills/system-prompt-refiner/TEST-MATRIX.md` — reusable 15-category test matrix.
- `skills/system-prompt-refiner/OUTPUT_TEMPLATE.md` — standard refinement report.
- `skills/system-prompt-refiner/references/TOOLING.md` — tool integration guidance.

## Import

Import this folder from GitHub using:

`https://github.com/trunggptplus22-debug/notebooklm-prompts/tree/main/plugins/system-prompt-refiner`

The plugin provides prompt-refinement instructions only. It does not bundle external model APIs, MCP servers, credentials, or execute/deploy prompts automatically.
